# UI SFX Studio audio

The MP3 files in this directory are selected cues from the `studio` sound pack
in UI SFX, downloaded from:

https://github.com/romainsimon/uisfx/tree/99d287a1d27ef49c02a5262184a7fda91612321e/packages/uisfx/sounds/studio

Source cue mapping:

- `purchase.mp3` — completed in-app payment
- `error.mp3` — action requiring attention
- `blocked.mp3` — rejected scan or delete feedback
- `select.mp3` — accepted scan or keypad feedback
- `notification.mp3` — new webshop order

The UI SFX audio library is dedicated to the public domain under CC0 1.0:

https://github.com/romainsimon/uisfx/blob/99d287a1d27ef49c02a5262184a7fda91612321e/LICENSE-AUDIO
